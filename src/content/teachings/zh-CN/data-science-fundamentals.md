## 课程简介

本课程系统介绍数据科学的核心原理与工业界实践经验。通过本课程的学习，学生将能够：

- 掌握端到端的数据科学完整分析闭环
- 熟练运用 Python 数据科学工具栈（Pandas, NumPy, Matplotlib）
- 具备数据可视化展示与技术汇报沟通能力
- 能够运用严谨的统计学方法从复杂数据中提炼洞见

## 先修

- 具备基础编程经验（推荐熟悉 Python 语言）
- 初等统计学基础
- 线性代数基本概念

## 推荐教材

- 《利用 Python 进行数据分析》（Wes McKinney 著）
- 《从零开始学数据科学》（Joel Grus 著）
